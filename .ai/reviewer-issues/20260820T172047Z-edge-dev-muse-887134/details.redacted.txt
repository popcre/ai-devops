RECOMMENDATION, and it is stronger than last time
1. Emit ONE line at session creation, before any provider call, naming the session and its
   state-file path. This is the single highest-value change: it distinguishes "never
   started" from "started and working" in one second instead of seventeen minutes, and it
   would have resolved all three of today's incidents immediately.
2. Add a startup watchdog: if no state file exists N seconds after invocation, fail loudly
   with a distinct code rather than continuing silently.
3. Investigate whether session creation can hang or fail without writing state AND without
   emitting anything on stdout or stderr. If it can, that is the defect.
4. Until 1-3 land, consider whether Muse should remain in the active rotation. It has failed
   3 times in 3 attempts at review work today (one refusal to start, two silent stalls) and
   succeeded once on a non-review recommendation task. That is a rotation slot that mostly
   costs time.
