This source preparation performed **zero network/SSH/API/credential access**.
Ordinary independent exact-head security/action review, truthful production gate,

and one-use claim remain mandatory before any live use. The genuine installed

a hash/dictionary/boolean is never production authority. No reviewer is run here.

Two separate contracts/claims are required:

1. **discover**: fixed GET `http://100.66.37.58:8000/api/v1/version` (public Coolify

   ps helper-ancestor inventory reads only ID/Image/Names/State, at most16 rows.

2. **qualify**: only after coordinator selects and independently reviews exact
   current CID/name/public image label and immutable image ID, inspect identity,
