## How to re-measure

Run from Git Bash in a scratch folder, once per repository:

```bash
ai-gh api "repos/popcre/ai-devops/actions/runs?per_page=100&created=>=YYYY-MM-DD" --paginate -q '.workflow_runs[] | [.name,.event,.conclusion,.status,.created_at,.updated_at,.run_started_at,.id] | @tsv' > runs.tsv
```

Then count by workflow name, event and conclusion. Compare the same window
length, and state the window in the report.
