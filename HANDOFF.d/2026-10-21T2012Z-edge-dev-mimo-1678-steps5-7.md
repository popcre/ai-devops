## 4. Everything we tried that did NOT work

- **`bin/ai-gh.cmd` from PowerShell** failed with "The system cannot find the path specified". Use `gh` directly or invoke via Git Bash (`"C:\Program Files\Git\bin\bash.exe" -lc '...'`).
- **PowerShell expands `$(...)` inside `bash -c "..."`** before bash sees it. Always quote bash payloads with single quotes: `bash -lc '...'`.
- **`bin/ai-task-gates explain` hangs on edge-dev** after printing a long "unprotected advances" warning log (timed out at 12–15s with no JSON). Engine and self-cleanup suites must mock `ai-task-gates` on `PATH` or `ai-review-sandbox with-copy` hangs in privacy classification.
- **`tests/test-ai-review-engine.sh` E2E can exceed 5–9 minutes on edge-dev** and `timeout N` inside the suite may not kill the Windows process tree cleanly. Unit-level checks placed early (right after sourcing `tools/lib/review-lifecycle-core.sh`) run in seconds and still prove the contract. Full suite is for CI.
- **Calling `rlc_write_report` with the wrong arity** (missing MODE/REPO) made `body="${10}"` empty → `cat: '': No such file` and "report assembly was empty". Signature is `OUT PROVIDER MODE REPO HEAD DIGEST RUN CALLER ELAPSED BODY_FILE [EXTRA]`.
- **Merge queue "stuck" for hours was a false alarm** — PR #1928 was queued behind other PRs and re-queued three times as `main` moved; it landed automatically. Do not treat a long queue as a broken queue without checking `gh run list` for `merge_group` runs.
- **First StepFun fix (PR #1807)** copied a bash *script* to `<shim>/bash.exe`; Node `spawnSync('bash')` then failed `UNKNOWN`. Reverted in PR #1848. Do not re-land that shape.
